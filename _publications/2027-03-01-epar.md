**EPAR** is a two-stage framework for RGB–3D industrial anomaly detection through embedding predictive adaptation and refinement.

**Stage 1 — Feature adaptation.** RGB images and 3D point clouds are divided into context and target regions.
The context encoders learn to predict target embeddings at multiple feature levels, with exponential moving average (EMA)
target encoders and variance–invariance–covariance (VIC) regularization.

![Stage 1: feature adaptation]({{ base_path }}/images/epar_feature_adaptation.png)

**Stage 2 — Anomaly map refinement.** Pseudo anomalies are synthesized in RGB images and 3D point clouds using foreground-aware masks.
With the adapted encoders and memory banks frozen, retrieved features train a Noise Suppression Network (NSN) against the pseudo-anomaly masks,
refining anomaly predictions through noise suppression.

![Stage 2: anomaly map refinement]({{ base_path }}/images/epar_refinement_stage.png)
